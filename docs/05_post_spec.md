# 05. Постпродакшн: титры, цвет, звук, экспорт

## Титры и обязательные подписи

Все титры, подписи, логотип и контакты накладываются **на монтаже**, внутри изображения их не генерируют.

| Подпись | Когда | Длительность |
|---|---|---|
| «Візуалізація можливого інтер’єру» | Любой кадр с ремонтом / мебелью, которых нет в реальности | Весь кадр, включая dissolve |
| «Концепція благоустрою» | Бассейн, площадки, зоны отдыха, скамейки, лежаки, навесы, освещение, которых нет в натуре | Весь кадр |
| «Візуалізація» | Вечерняя переработка, если она существенно меняет сцену | Весь кадр |
| «Ілюстративна сцена» | Люди, добавленные в реальный кадр | Весь кадр |

- Если заказчик подтвердит проектный статус объекта, подпись заменяется на согласованную, например «Проєкт благоустрою, черга N».
- Расположение подписей: 16:9 — справа сверху; 9:16 — по центру на 13% высоты. Кегль не меньше 2,4% высоты кадра; полупрозрачная плашка.
- Шрифт в аниматике — Inter (Light / Display Light). Если у Green Park есть фирменный шрифт с кириллицей, используется он.
- Безопасные зоны:
  - 16:9 — title-safe 90%;
  - 9:16 — текст не выше 12% и не ниже 78% высоты, справа 120 px свободны под интерфейс соцсетей.

## Цвет и изображение

- **Исходники iPhone.** Видео, скорее всего, HEVC 10-bit HLG / Dolby Vision. Рабочее пространство — Rec.709 Gamma 2.4.
  - DaVinci Resolve: CST Rec.2100 HLG → Rec.709, tone mapping «Luminance», saturation mapping вкл.
  - ffmpeg (превью, так работает `tools/animatic.py`): `zscale=t=linear:npl=203,format=gbrpf32le,zscale=p=bt709,tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv`.
- **Пробы.** Фото — SDR-слой HEIC; при необходимости вытянуть тени из gain map.
- **Окна.** Не допускать выгоревших окон. Маска на окно, highlight recovery. Оставлять пересвеченные кадры, а не «серый HDR».
- **Единая гамма.** Сессия одна: пасмурно, осень. Слегка тёплый баланс (+150–250 K), мягкий контраст, натуральная зелень без ядовитости. Газон и туи −5…−10% насыщенности в зелёном.
- **Ультраширик (0,5×).** Коррекция дисторсии, выравнивание вертикалей. Ремонт генерировать только после коррекции.
- **Стабилизация.** Resolve Stabilizer, режим Similarity, zoom ≤ 8%, без Perspective, чтобы не «дышали» стены. В `tools/animatic.py` для превью используется `deshake`.
- **Чистка кадра.** Мусор и поддоны убираются кадрированием, без перерисовки. Строительный вид за окном (IMG_7865, IMG_7872) не меняется: ТЗ запрещает выдумывать виды.
- **Частота кадров.** Аниматик собран в 25 fps. После получения MOV проверить `r_frame_rate`. При 30 или 60 fps таймлайн ставится на 30 fps (поле `fps` в JSON); 60 fps используется как slow-motion 50%.

## Монтаж

- Длительность кадров: 2–4 с; переходы «до/после» — 4–6 с суммарно (реальный кадр + dissolve 0,8–1,0 с + ключевой кадр).
- Сцены с людьми длятся не меньше 2,6 с, чтобы действие успело прочитаться.
- Камера на фото: наезд 2–10% или панорама ≤ 8% ширины кадра. Новые помещения в кадре не появляются.
- Склейки — по движению или по свету, без «эффектных» переходов.

## Звук

- **Музыка.** Лицензия на рекламное использование (Artlist / Musicbed / Epidemic с коммерческой лицензией). Мягкое инди или фортепиано, лёгкий органический ритм, 80–95 BPM, развитие к 1:05 (общая жизнь) и раскрытие к финалу.
- **Шумы.** Шаги по брусчатке, листва и ветер в соснах (открытие), отдалённые детские голоса (65–80 с), вода (кадр бассейна — тихо), разговор соседей неразборчиво, двери террасы.
- **Диктор.** Украинский, тёплый, спокойный, без «рекламного» напора; паузы — по `renders/*_vo.srt`.
- **Микс.**
  - Музыка под диктором −8…−10 dB (ducking).
  - Интернет-версии: −14 LUFS integrated, true peak −1 dBTP.
  - ТВ-версии (если будут): −23 LUFS (EBU R128).
- **Две версии:**
  - **с диктором** (`*_VO`);
  - **без диктора** (`*_NOVO`) — музыка и шумы, смысл несут титры. Для 9:16 — вшитые субтитры (`*_vo.srt`).

## Экспорт

| Версия | Формат | Параметры |
|---|---|---|
| Мастер 90 с | 3840×2160 (если исходное видео 4K; фото позволяют), иначе 1920×1080, 16:9 | MP4 H.264 High, 35–45 Mbps (4K) / 16 Mbps (HD), AAC 320k 48 kHz, Rec.709 |
| 30 с и 15 с | 1080×1920, 9:16 | MP4 H.264 High, 12–16 Mbps, AAC 256k |
| Дома ×3, квартиры ×4, территория | 1920×1080 или 3840×2160, 16:9 | Как мастер |

Именование: `GreenPark_<ролик>_<формат>_<VO|NOVO>_v<NN>.mp4`.
