**Как сделаны:**

- Размеры помещений взяты из АР.
- Колонны, балки, окна и скаты стоят на тех же местах, что на фото коробки.
- **Вид за окнами — реальные фото Green Park** (IMG_7850, 7857, 7858, 7872), а не выдуманный пейзаж.

Каждый кадр с ремонтом идёт в роликах с подписью «Візуалізація можливого інтер’єру».

Сцены лежат в `tools/blender/s*.py`, общая библиотека — `gp_lib.py`. Перерендер всех сцен:

```bash
pip install bpy pillow numpy
tools/blender/render_all.sh 1920 1080 128     # + вертикальные версии
CAM=match python3 tools/blender/s2_house2_studio.py out.png   # ракурс точно как на фото коробки
```

## Монтаж (`renders/promo/`)

| Ролик | Формат | Длина |
|---|---|---|
| `master_promo_16x9.mp4` | 16:9 | 53,6 с |
| `cut_promo_30_9x16.mp4` | 9:16 | 30 с |
| `teaser_promo_15_9x16.mp4` | 9:16 | 15 с |

Приёмы:

- **Переход «до/после»** — шторка со светлой линией: реальная коробка (фото) превращается в визуализацию ремонта.
- Плавные наезды на фото и визуализации.
- Световые вспышки на сменах блоков.
- Кинетические титры: слово за словом, с линией-акцентом.
- Тёплые блики, плёночное зерно, виньетка.

Сборка: `python3 tools/promo.py promo/*.json --music renders/promo/music_master.wav`.

**Музыка** `renders/promo/music_*.wav` сгенерирована (`tools/music.py`): мягкие арпеджио, пэд, лёгкая перкуссия, −15 LUFS. Это **временная подкладка**. Для публикации её нужно заменить на лицензированный трек (см. 05).

## Чего пока нет

- **Дуплекс и квартиры 47–55 / 60 м²** — нет фото и видео. Визуализации делаются после получения материала (см. 02, §4).
- **Люди в кадре.** В 3D-визуализациях жизнь передана предметами: чашки, плед, настольная игра, книги, свет ламп. Живые люди требуют видеосъёмки или генеративной модели (см. 04).
- **Видео из Drive (MOV)** по-прежнему недоступны в этой среде.
