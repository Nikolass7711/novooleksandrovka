# 03. Сценарии

Концепция: **«Green Park — простір для свого життя»**. Сюжет идёт так: пространство → дом → личная жизнь → соседи → общий отдых → приглашение на просмотр.

Покадровые таблицы с таймкодами, исходниками, обработкой, титрами и статусами лежат в `renders/<имя>.csv`. Их генерирует `tools/animatic.py` из `timelines/<имя>.json`. Субтитры диктора — в `renders/<имя>_vo.srt`. Ниже описаны режиссёрский замысел каждого ролика и правила, которые таблица не передаёт.

Статусы кадров:

- **реальне фото / реальне відео** — съёмка объекта; допускаются только цвет, стабилизация и кадрирование;
- **візуалізація інтер’єру** — возможный ремонт. Титр «Візуалізація можливого інтер’єру» стоит весь кадр;
- **оживлення реального кадру** — реальная территория, люди добавлены. Подпись «Ілюстративна сцена» стоит весь кадр;
- **концепція благоустрою** — объекты по схеме, ещё не реализованы. Титр «Концепція благоустрою» стоит весь кадр;
- **візуалізація (вечір)** — существенная переработка света. Подпись «Візуалізація» стоит весь кадр;
- **ПРОГАЛИНА** — материала нет, кадр ждёт досъёмки (см. 02, §4).

## 2. Рекламная версия 30 с, 9:16 (`cut_30_9x16`)

Фасад и сосны с титром «Простір для свого життя» → улица → площадь с людьми → навес и титр «Будинки · дуплекси · квартири» → дом 1 «до/после» → дуплекс → смарт «до/после» → дети на улице → вечерний фасад → финальная карточка (4,4 с).

Вертикальная версия выходит с вшитыми субтитрами диктора: в лентах видео автоматически стартует без звука.

## 3. Тизер 15 с, 9:16 (`teaser_15_9x16`)

Фасад с титром → улица → коробка → тот же ракурс с ремонтом → площадь с людьми → финальная карточка. Одна мысль: «вот реальное место, вот каким может быть ваш дом».

## 4. Ролики домов (25–35 с, 16:9)

Структура: фасад и вход → реальное помещение → ремонт в том же ракурсе → 2–3 подходящих пространства → терраса или участок, если подтверждены → приглашение.

Внутри каждого дома держится **один** дизайн-проект: палитра, мебель, расположение дверей. Это обеспечивают общие «библии» стиля H1/H2/H3 в 04.

| Ролик | Длина | Стиль | Мини-сюжет | Пробелы |
|---|---|---|---|---|
| `house1_136_16x9` | 27 с | Тёплый современный: светлый дуб, молочные оттенки, уютная общая зона | Возвращение домой: подъезд под навес → кухня-гостиная 46 м² (коробка → ремонт) → реальный white box → тот же ракурс с ремонтом → выход на террасу → семейный ужин | Спальня (G4) |
| `house2_174_16x9` | 26,6 с | Европейский современный: натуральный камень, дерево, спокойная графика | Простор для большой семьи: проход по коробке (видео 7890) → три ракурса «до/после» в одном проекте | Фасад (G2), терраса (G3) |
| `house3_duplex_16x9` | 25 с | Мягкий минимализм: светлые стены, фактуры, лаконичная мебель, приватные зоны | Два уровня — два ритма: общая студия внизу, тишина наверху, вечер на террасе 2-го уровня | Фото и видео дуплекса (G1, G5) |

Кухни, спальни и кабинеты показываются только там, где они есть в плане АР. Назначение зон на фото 7886, 7889 и 7878 нужно подтвердить по плану до генерации.

## 5. Ролики квартир (20–30 с, 16:9)

Структура: реальный вид → исходное помещение → ремонт → 2–3 детали организации пространства → финальная сцена жизни и CTA.

| Ролик | Длина | Сценарий | Основание |
|---|---|---|---|
| `apt1_smart_16x9` | 21,4 с | Утро одного человека и работа из дома | 31–43 м², одна жилая зона; на фото — угловое окно |
| `apt2_47_16x9` | 20,2 с | Жизнь пары | Презентация: «для пари чи родини з дитиною». **Ждёт плана и съёмки** |
| `apt3_60_16x9` | 20,2 с | Семейное время | **Ждёт плана**: число комнат не подтверждено |
| `apt4_108_16x9` | 23,4 с | Семейный вечер: «простір будинку у форматі квартири» | 107,9 м², помещения под скатной кровлей |

Не добавлять: балконы, второй уровень, мансардные окна в скатах, панорамные окна, лишние спальни. Компактная квартира остаётся компактной. Мебель — реального масштаба, дверные проёмы — на своих местах.

## 6. Территория и комьюнити (32,8 с, 16:9) (`territory_16x9`)

Реальная улица, изгородь, площадь, сосны → дети на велосипедах, приветствие соседей, человек с собакой → концепция бассейна, детской площадки и зоны отдыха по схеме → финальная карточка.

Людей мало и они соответствуют масштабу кадра. Маршруты логичные: по тротуару и проезду, без прохода сквозь машины и заборы. У воды всегда есть взрослые. Улыбок в камеру нет.
