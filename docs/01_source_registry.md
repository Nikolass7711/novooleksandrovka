# 01. Реестр исходников

Источник: Google Drive, папка проекта (выгрузка 13.10.2026). Фото сняты 13.10.2026 на iPhone, с 13:41 до 14:26, пасмурно, осень (жёлтые листья). Для монтажа это одна дневная сессия, поэтому свет и сезон во всех кадрах совпадают.

**Обозначения.** Пригодность: **A** — герой-кадр; **B** — рабочий кадр; **C** — только как опора для AI или вообще не использовать. «Реставрация» — подходит ли кадр как опорный ракурс для перехода «без ремонта → с ремонтом». «Оживление» — подходит ли для добавления людей.

**Видео в реестр не вошли.** Ни один из 13 MOV не удалось загрузить в рабочую среду (см. раздел «Видео» ниже), поэтому таймкодов по ним пока нет. Когда файлы окажутся в `assets/video/`, их таймкоды дописываются в эту таблицу. Скрипт сцен уже ссылается на эти видео как на слоты.

Когда видео окажутся в `assets/video/`, выполнить для каждого:

```bash
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,color_transfer,color_primaries -of compact assets/video/IMG_7854.MOV
ffmpeg -i assets/video/IMG_7854.MOV -vf "fps=1/2,scale=480:-1,tile=6x4" -frames:v 1 assets/video/IMG_7854_contact.jpg
```

Затем дописать в таблицу таймкоды полезных фрагментов и поставить точки `in` в `timelines/*.json`.
