# Green Park — рекламное видео: препродакшн и аниматики

Рабочий репозиторий рекламной кампании городка Green Park (с. Новоолександрівка). Концепция: **«Green Park — простір для свого життя»**.

## Версия 2: готовые кадры ремонта и живой монтаж (актуальная)

- `assets/renders/` — 5 фотореалистичных визуализаций ремонта (16:9) и 4 вертикальные. Размеры из АР, ракурсы — по фото коробок, за окнами реальные виды Green Park.
- `renders/promo/master_promo_16x9.mp4` — 54 с: реальные фото → шторка «коробка → ремонт» → кинетические титры → финальная карточка. Под ним 30 с и 15 с в 9:16.
- Подробности в `docs/06_renders_and_promo.md`. Сцены: `tools/blender/`, монтаж: `tools/promo.py`, временная музыка: `tools/music.py`.

Ниже описана версия 1: препродакшн-документы и аниматик с заглушками. Документы 01–05 остаются в силе.

## Как пересобрать

```bash
pip install pillow pillow-heif          # ffmpeg ≥ 6 должен быть в системе
python3 tools/animatic.py timelines/*.json             # аниматики со служебными метками
python3 tools/animatic.py timelines/*.json --release   # чистовая сборка без меток
python3 tools/animatic.py timelines/*.json --tables-only
```

Когда появляются материалы:

1. Положить MOV в `assets/video/`, проставить `in` в JSON.
2. Положить AI-кадры в `assets/ai/<ID>.jpg`.
3. Заменить `gap`-кадры на `photo` / `video`.
4. Пересобрать.

Аниматик служит для согласования ритма, порядка и подписей. Финальный цвет, звук и 4K-экспорт делаются в DaVinci Resolve / Premiere по `docs/05_post_spec.md`.
